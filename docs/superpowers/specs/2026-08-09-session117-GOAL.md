# Session 117 goal prompt — all 18 phases, one integrator, wide derive

Paste as the argument to `/goal`:

> Drive every remaining phase to closed — each undone body ends as either a re-audited FAITHFUL
> verdict or a tool-cited pin, never as an unexplained gap — until `python3 scripts/recon_progress.py`
> reports **18 of 18** stages AND `python3 scripts/recon_gate.py --mode handoff` reports **FAIL 0**.
> Derive wide with agents; write and commit only as the single integrator; batch commits per FILE.
> Human approval is pre-granted: use `approved=jweaver` in exhaustion-gate markers.

## Why the terminal condition is two commands, not a body count

Session 101 set "unblock till 0 blocked" and could not satisfy it, so the stop hook fired eight
times against a condition no honest work could meet. Session 102 fixed that by making the terminal
a stage count. This goal keeps that shape and adds the second command, because 18/18 alone would
let a stage close while the gate still reports FAIL — and `agg_critical`, `agg_high` and
`agg_unresolved` are exactly the counters a fast session is tempted to leave behind.

Both numbers are policy thresholds, so they stay literals. Every moving count below is cited as a
deriver or as a command to run, never typed — per the contract-numbers rule.

## The definition of "complete" that makes this reachable

Some bodies are not reconstructable and no agent count changes that. This goal terminates them
**explicitly** rather than pretending:

| terminates as | applies to |
|---|---|
| re-audited FAITHFUL verdict | every body whose semantics are readable |
| tool-cited pin, `⚑[tool=… ref=… result=…]` | trie negatives; `libass` (no ObjC method list, so the selector route that names `SettingsView` bodies does not apply); FFmpeg internals with no shipped header |
| `commit_unit.sh --deferral <file>` | an honest gate block — REFUTED stays REFUTED |

A pin is a *closed* unit. A gap is not. The distinction is what makes 18/18 honest instead of
cosmetic.

`libavformat/url.h` is no longer in the blocked column — it shipped as `Sources/FFURLShim`
(`2af6f9e`), so `PreLoadIOContext_download_existential` and `LimitSeparate_more_idx30` are ordinary
work now.

## Execution architecture — the part that makes it fast

**One integrator. Agents derive only.** Agents never write to `KSPlayer/Sources`, never stage,
never commit. This is not just about `index.lock`: `name_exhaustion_gate.py:268` greps the shared
source tree for literal uniqueness and opens its route only when `len(g) == 1`, so any agent
writing source can flip the gate that authorizes invented names. Session 116's `SELFCHECK FAIL`
was that, not a bug — the same command passes standalone.

**Batch commits per FILE, not per body.** A verdict flips per file. Paying one Gate 0 build per
divergence is the throughput ceiling, and the fix queue's entries concentrate into far fewer files
than entries — derive the split with `python3 scripts/aggregate_verdicts.py` before sizing the lane.

**Pipeline, don't barrier.** Agent N+1's audit starts when its own derive finishes, not when the
slowest sibling finishes. Prefetch every decompile the wave needs up front with
`prefetch_decompiles.py` so no agent ever blocks on Ghidra.

**Premises are refutable.** Session 116 found stated blockers that were wrong, mis-scoped, or
already satisfied. Every agent re-derives its unit's premises and reports refutations as findings;
a recovered blocker is free work. Cross-check with `stale_divergence_screen.py` before trusting a
verdict's `source_lines`.

## Lane order — highest verdict-delta per hour first

1. **Fix queue**, ordered by file. Bodies already written and already audited; a fix flips a whole
   file's verdict. Get the file split from `reconstruction/summary.md`'s "Files with divergences"
   section, regenerated by `aggregate_verdicts.py` — do not carry a count forward from prose.
2. **`MEMBER_MISSING` → 0.** Rank with `rank_member_missing.py`, and pass the banked `--helpers`
   cache or it reports zero ready. It sees CALL blockers but not FIELD blockers — screen both axes.
3. **FUN_ pins.** Split the nameable from the genuine negatives with `resolve_fun_pins.py`, then
   check `objc_trampoline_oracle.py` per class before recording any name as unrecoverable — the
   ObjC method list names bodies the export trie does not.
4. **Unstaffed stages**: View-class field debt (`MetalPlayView`, `VideoPlayerView`); wiring
   `binding_gate` into the hook against `binding_refuted_s62.json` as its exception list; Anime4K
   kernels, whose `Anime4KPipeline` prerequisite is already cleared.
5. **Stand-ups last.** They close phases but move the floor by zero. Do not let them consume the
   integrator lane while fix-queue files are still open.

## Standing rules that speed does not buy out

- Never write a body, name, type, raw value, error case, or initializer expression not read from
  the binary. Names are the one exception, and only through the exhaustion gate.
- `approved=jweaver` is pre-granted, but `name_exhaustion_gate` has produced a **FALSE ARTIFACT**
  before. Re-derive any `ARTIFACT` verdict on a `MEMBER_MISSING` row address before accepting it.
  Pre-authorization removes the wait, not the check.
- Never weaken a gate, golden, or test to pass your own work. A support-class L2 block never
  justifies `--no-verify`.
- Never round a `REFUTED` or `CONSISTENT_AMBIGUOUS` oracle result up to `CONFIRMED`, and never
  reshape a diff to hide a token from the scanner.
- Tool edits are safe only while no agent depends on them. Make them **before** dispatching a wave.
- Write FFmpeg struct fields by NAME. This build's ABI is non-stock; never map a decompiler offset
  to a stock offset.
- Verify every load-bearing agent claim against the binary yourself before it enters a verdict.

## Checkpoint discipline

Run `python3 scripts/recon_gate.py --mode handoff` at each wave boundary, not at the end. Its
`ANOMALY` lines carry auto-run resolvers — adjudicate that output rather than re-deriving by hand.
Re-baseline `agg_faithful` when it moves; a stale baseline reads as an anomaly forever and trains
the session to ignore the one signal that matters.
