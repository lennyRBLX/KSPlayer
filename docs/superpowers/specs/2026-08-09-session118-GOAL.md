## The rule that makes this finishable: recurse, don't pin

Session 117 stalled because "blocked" was a terminal state. It is not. When a unit cannot be
written, **the thing blocking it is the next unit** — push it on the stack and go. Depth-first
until the leaf is writable, then unwind. A pin is only for a leaf that is provably unreachable
after the exhaustion gate has run, not for anything that merely has a dependency.

Concretely, all four of these are units, not walls:

| you hit | you do |
|---|---|
| a member the binary calls and source lacks | reconstruct that member |
| a type source spells differently from the binary | retype it, and reconstruct whatever that breaks |
| a name absent from the trie | run the exhaustion gate, invent with `approved=jweaver` + `invented=` |
| a stage gated on a tool nobody wrote | write the tool |

That last row is the one that trapped s117: the unresolved-symbol stage routes to a
`masked_twin.py` that does not exist, so 18/18 was unreachable by construction. Building it is in
scope. So is anything else a stage needs.

## Pre-approved, so never wait

`approved=jweaver` covers every judgement call: invented names through the exhaustion gate,
access-level widening, file placement, enum case naming, spelling choices between two
observationally identical lowerings. Record the choice and the evidence; do not pause for a ruling.

Two things approval does NOT buy, because they corrupt the artifact rather than decide it:

- Writing a body, value, or type you have not read. Approval removes the wait, not the check.
- Editing a gate, golden, or expected value so your work passes. If a golden fails **because your
  work changed the world**, re-anchor it on the invariant it means to test — that is required, not
  forbidden. Editing the expected number is what is forbidden.

## Compaction is a checkpoint

Keep `reconstruction/RESUME.md` current — overwrite it whenever the stack changes, and always
before a long agent wave. It holds exactly four things:

1. the unit stack, deepest-first, each with its address and its one-line blocker
2. the next concrete action, precise enough to execute without re-deriving
3. anything derived-but-not-yet-applied, with the file it lives in
4. the last measured gate line, and whether the tree is green

After compaction: read `RESUME.md`, run `recon_gate --mode handoff`, continue. Do not re-derive
what the derivations directory already holds. Do not re-plan.

## Fastest known methods

**Screen before dispatch.** Every fix-queue unit in s117 carried a false premise; two named
blockers already satisfied in committed code. Verify each premise by NAME against current source
first — a minute against an agent.

**Flip stale verdicts first — they are free floor.** Fixing source and adjudicating are two acts,
and only the flip counts. One s117 flip earned +5 with zero source edits.

**Batch per FILE.** A verdict flips per file; fixing three of nine divergences moves nothing. One
gate per file, not per divergence.

**Fan out wide on derivation, single-thread integration.** Agents write findings to
`reconstruction/derivations/<unit-id>.md` and return ≤15 lines. Dispatch the whole frontier at
once; you are the only writer. Prefetch decompiles for a wave up front so no agent blocks on Ghidra.

**Recurse into the cheapest leaf first.** When a unit has several blockers, take the one whose own
dependency tree is shallowest — it unwinds the most for the least context.

**Never accept "unnamed" as "unreadable".** An absent trie symbol still has a fully readable body.

**Check for an existing same-file accessor before widening access.** A cross-file `private` call is
usually reachable through a member the owning file already declares.
